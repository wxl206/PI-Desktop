# 05. 新手引导

> **翻译说明：** 本页是与 [英文源规格](/spec/04-ux/05-onboarding) 一一对应的机器辅助翻译。代码、协议字段和标识符保持原文；如翻译与英文源事实有歧义，以英文版本为准。


## 1. MVP 的决策

使用**内联首次运行清单**，而不是多页模式向导。

理由：

- 更快地获得第一个值
- 更少的阻塞
- 更容易使用 skip/return

## 2. 首次运行检测

当满足以下任一条件时显示检查表：

1. 没有配置提供商
2.默认提供商没有秘密存在
3. 尚无会话存在

保留解雇状态，但不完整的关键步骤可能会重新显示为横幅。

当 `AppSettings.iterateWelcomeDismissed` 缺失或为 false 时，空首页会优先显示
「迭代」账户引导。用户选择**稍后**，或账户、专用 Key 与模型接入全部完成后，
该引导才会在当前及后续启动中保持隐藏。已恢复的账户会话只会预填账户步骤；
在模型接入完成前，引导仍然可见。用户直接配置其他 OpenAI 兼容服务商时，
通用服务商/密钥清单继续作为备用路径。

引导会等待持久化设置加载完成后再显示或查询账户，避免慢启动时闪现首次运行
卡片。已关闭的引导不会查询账户。设置存储不可用时，**稍后**和完成接入都不能
被当作已保存；界面报告 `STORAGE` 并继续显示引导。账户加载发生临时错误时，
界面提供内联重试和**稍后**入口，用户仍可进入应用。

## 3. 检查清单步骤

「迭代」主路径包含三个步骤：

1. **连接「迭代」账户并完成模型接入**
2. 在第三方商店**充值或兑换额度**
3. 需要更换时**选择其他模型**

第一步会为服务端返回的第一个可用分组创建或复用专用 Key，读取该 Key 可见且
协议可识别的模型，接入第一个可用模型；只有当前没有可运行的默认模型时，才会
将其设为应用默认。用户仍可进入设置选择其他分组或模型。

备用直连服务商清单保留：

1. **添加提供商**
2. **保存 API 密钥**
3. **打开项目文件夹**
4. **发送您的第一个提示**
5. *（可选）* 加载开发插件

## 4. 安置

- 显示在主聊天空白状态
- 「迭代」连接步骤会打开隔离的网站登录窗口，并在会话确认后创建或复用专用 Key
- 登录后会读取首个可用分组的模型并接入第一个响应格式已知的模型；没有可用分组
  或兼容模型时，引导保持可见并指向设置 →「迭代」
- 初始化失败时，首次运行卡片保留重试操作和正常**稍后**入口；普通操作失败不会
  用错误页替换该卡片
- 充值和兑换只有在明确确认第三方交接后，才打开隔离的应用内商店窗口
- 模型步骤深层链接至设置 →「迭代」，用于选择其他模型
- 提供商和关键项目深层链接至“设置”→ Agent
- 可选插件项打开应用程序外壳的插件目的地
- 项目和提示项调用其相关的应用程序操作
- 核心步骤完成后清单会崩溃

## 5. 复制提示音

英文源码，简洁，行动导向。

示例：

- “添加模型提供商”
- “保存您的 API 密钥”
- “打开项目以启用本地工具”
- 充值文案必须说明付款在第三方站点完成；收到的兑换码由用户在设置 →「迭代」
  明确提交，PI-Desktop 不会自动扣款或自动兑换。

## 6. 非目标

- 帐户注册
- 云同步设置
- 长产品巡演覆盖
- 为回访用户提供强制教程

## 7. 验收

1. 新鲜的个人资料显示清单
2. 记录**稍后**会在重启后保持隐藏
3. 已恢复的「迭代」账户仍需完成 Key 与模型接入，引导才会消失
4. 成功接入会隐藏引导并持久化；仅恢复账户不会
5. 取消充值不会打开商店，明确确认只打开一次
6. 完成 provider+key+prompt 会移除关键空状态阻塞
7. 关闭可选步骤不会影响应用继续使用
8. 仅在设置加载完成后显示并查询引导；设置写入失败时引导保持可见并报告存储错误
9. 账户初始化失败时同时提供重试和**稍后**入口
